[Enumerable\#each_with_object \(Ruby 4\.0 リファレンスマニュアル\)](https://docs.ruby-lang.org/ja/latest/method/Enumerable/i/each_with_object.html) <br>
each_with_object(obj) -> Enumerator<br>
each_with_object(obj) {|(\*args), memo_obj| ... } -> object

与えられた任意のオブジェクトと要素をブロックに渡し繰り返し、最初に与えられたオブジェクトを返すメソッド。(説明よりも挙動を見ると分かりやすかった)
